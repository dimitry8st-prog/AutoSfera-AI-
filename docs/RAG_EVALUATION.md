# Оценка качества RAG AutoSfera

## Назначение

Фиксированный набор `evals/rag_cases.json` проверяет не только наличие ответа, но и правильность поиска, корректный отказ, разграничение доступа, задержку и наличие метаданных актуальности. Стартовые вопросы являются демонстрационным baseline; перед пилотом их нужно дополнить обезличенными реальными формулировками клиентов и сотрудников.

## Запуск

TF-IDF baseline без внешних ключей:

```bash
RAG_BACKEND=tfidf python scripts/evaluate_rag.py
```

Проверка pgvector после миграции и индексации:

```bash
RAG_BACKEND=pgvector EMBEDDING_MODE=openai python scripts/evaluate_rag.py
```

Добавьте `--enforce`, чтобы вернуть ненулевой код при нарушении хотя бы одного порога. Обычный CI запускает evaluator без `--enforce`: baseline обязан формировать отчёт, но известные пробелы демонстрационной базы не должны маскироваться или блокировать проверку самого кода.

Отчёты сохраняются в `reports/rag-eval/report.json` и `report.md`.

## Автоматические метрики и ворота пилота

| Метрика | Стартовый порог | Смысл |
|---|---:|---|
| Retrieval hit rate | 85% | ожидаемый документ найден в `top_k` |
| Корректный отказ | 100% | запросы вне базы не получают случайный контекст |
| Безопасный ответ-отказ | 100% | агент эскалирует запрос вне базы вместо выдуманного ответа |
| Покрытие контрольных терминов | 85% | в ответе присутствуют обязательные проверяемые факты |
| Нарушения доступа | 0 | агент не получает запрещённые разделы |
| Retrieval latency p95 | ≤ 2000 мс | ограничение задержки поиска |
| Метаданные актуальности | ≥ 90% | документ имеет версию, владельца и статус `approved` |

Совпадение контрольных терминов не называется фактической точностью. Ответы дополнительно оцениваются человеком по шкале 0–2: точность, полнота, релевантность, понятность, источники и безопасность.

## Решение

- `GO` — все автоматические ворота пройдены и ручная проверка не выявила критических дефектов.
- `ITERATE` — хотя бы один автоматический порог не пройден; исправляются данные, чанкинг, промпт или параметры поиска.
- `STOP` — обнаружена утечка данных, опасное действие или критическая галлюцинация.

Порог similarity, `top_k` и reranking изменяются только после анализа зафиксированных ошибок, а не ради повышения одной метрики.
