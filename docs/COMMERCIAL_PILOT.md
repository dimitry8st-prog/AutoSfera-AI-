# AutoSfera AI — коммерческий MVP

## Назначение

AutoSfera AI — мультиагентная платформа для одного автосалона. Она автоматизирует первичную консультацию, поддержку клиентов, сервисные обращения и поиск внутренних регламентов сотрудниками.

Рабочий слоган: **«Единый интеллект автодилера»**.

## Границы MVP

В пилот входят:

1. Sales Agent — подбор автомобиля, кредит, лизинг, Trade-in и тест-драйв.
2. Customer Support Agent — статусы заказов, документы и обращения клиентов.
3. Service Agent — гарантия, ТО, эксплуатация и запись в сервис.
4. Employee Agent — регламенты, скрипты, процессы и эскалация руководителю.
5. Web-чат, HTTP API, база знаний и журнал диалогов.
6. Регистрация лидов, тест-драйвов и сервисных заявок.
7. Базовая аналитика обращений, эскалаций и заявок.

В версии 2.1 реализованы демонстрационные роли, постоянные сессии, кабинет заявок и защищённый контур исследований. В следующую production-итерацию входят корпоративный Identity Provider, реальный Telegram webhook, PostgreSQL + pgvector, загрузка документов и CRM/MCP.

## Масштабирование

Каждая запись диалога и заявки содержит `dealer_id`. В пилоте используется один идентификатор `main-salon`. При переходе к сети добавляются таблицы дилеров, филиалов и пользователей, а SQLite заменяется PostgreSQL без изменения публичных бизнес-моделей API.

## API пилота

| Метод | Endpoint | Назначение |
|---|---|---|
| `POST` | `/api/chat` | Диалог с оркестратором и агентами |
| `POST` | `/api/requests` | Создание лида, тест-драйва или сервисной заявки |
| `GET` | `/api/requests` | Список заявок текущего салона |
| `GET` | `/api/analytics/summary` | Сводные показатели салона |
| `GET` | `/api/knowledge` | Просмотр демо-базы знаний |
| `GET` | `/health` | Состояние платформы и конфигурация салона |

## Критерии готовности пилота

- четыре типа обращений корректно маршрутизируются;
- диалоги не теряются после обработки API;
- заявки изолированы по `dealer_id`;
- аналитика считается из сохранённых данных;
- отсутствие данных приводит к безопасной эскалации;
- автоматические тесты проходят полностью;
- демо запускается без внешнего LLM в `LLM_MODE=mock`.
