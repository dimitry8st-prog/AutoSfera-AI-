# Тестовые диалоги AutoSfera

## 1. Покупка кроссовера в кредит
- Пользователь: «Хочу купить кроссовер»
- Orchestrator → SALES_AGENT / Vehicle Selection → Nova Drive
- Пользователь: «Какие условия кредита?»
- Credit & Leasing → взнос 20%, до 60 мес., от 9,9%

## 2. Статус заказа
- Пользователь: «Статус заказа АН-2024-0512»
- Orchestrator → SUPPORT_AGENT / Order Status
- Ответ: Nova Drive Premium, предпродажная подготовка, 3 дня

## 3. Гарантия
- Пользователь: «Вопрос по гарантии на кузов»
- Orchestrator → SERVICE_AGENT / Warranty Consultation
- Ответ: 6 лет; подтверждение случая — только инженер

## 4. Лизинг B2B
- Пользователь: «Лизинг для юридических лиц на 5 авто»
- Orchestrator → SALES_AGENT / Credit & Leasing
- Ответ: от 8,5%, аванс от 10%, до 48 мес.

## 5. Квалифицированный лид в несколько сообщений
- Пользователь: «Ищу кроссовер до 3 млн и хочу передать заявку менеджеру»
- Sales Agent уточняет имя и телефон; Action Gateway ещё не создаёт действие
- Пользователь: «Меня зовут Дмитрий, телефон +79991234567»
- LangGraph сохраняет контекст → `vehicle_selection` → действие `lead` со статусом `waiting_approval`
- До approve заявки в CRM нет; после approve роли `sales` создаётся ровно один лид

## 6. Защита от дубля
- Пользователь повторно отправляет те же контактные данные в той же сессии
- Action Gateway возвращает существующее действие по idempotency key
- В CRM после подтверждения остаётся одна заявка

## 7. Недостаточно данных
- Пользователь: «Передайте заявку менеджеру, нужен кроссовер»
- Sales Agent просит имя и телефон
- Действие и заявка не создаются

## 8. Проверка ролей
- Service Agent пытается подтвердить лид продаж
- API возвращает `403`; действие остаётся на согласовании
