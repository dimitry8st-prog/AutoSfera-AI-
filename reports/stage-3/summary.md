## Исправление этапа

Старый тест ожидал, что после фразы «передай менеджеру» Sales Agent продолжит автоматический диалог. Это противоречило принятому правилу явного подключения человека. Проверка приведена к действующему контракту: запрос немедленно получает маршрут `human`, цель `sales_manager` и признак эскалации.

## Ограничение среды проверки

Docker в локальном рабочем контейнере отсутствует. Поэтому реальный PostgreSQL, Compose и n8n должны быть подтверждены заданиями GitHub Actions перед объединением ветки с `main`. Два пропущенных локальных теста относятся к интеграциям, требующим внешней инфраструктуры.

## Критерий объединения

Ветку можно объединять с `main` только после успешного завершения GitHub Actions: Python 3.11/3.12, PostgreSQL integration и n8n sandbox E2E.
