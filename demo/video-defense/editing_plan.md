# Монтажная карта

Целевой хронометраж: **5–7 минут**. Голос всегда громче музыки.

## Звук

| Дорожка | Уровень | Примечание |
|---|---|---|
| Озвучка `vo/*.mp3` | 0 dB (нормализация −16 LUFS) | Мужской `ru-RU-DmitryNeural` |
| Фон | **−18…−22 dB** относительно голоса | Тихая классическая скрипка |
| Субтитры | Sidecar `subtitles.srt` + опционально burned-in | Нижняя треть, отступ от UI чата 80 px |

**Музыку Ванессы Мэй в комплект не входит как коммерческая запись.** В сборке используется лицензированное исполнение Вивальди «Времена года» (John Harrison / Wichita State University Chamber Players, CC BY-SA) — см. `assets/BGM_LICENSE.txt`. Громкость фона около **−20 dB** к голосу, с ducking под речь.

## Видеодорожка

1. Слайды `stills/01`–`05`, `12`–`15` — длительность = длина соответствующего VO.
2. Живой чат `captures/s1`–`s6` — под VO сцен 06–11; можно слегка укоротить ожидание ответа, **не ускорять** сам ответ.
3. Переходы: **crossfade 8–12 кадров** (≈0,3 с). Без вылетов и 3D-вращений.
4. Цвета: `#0B1B3A` тёмно-синий, `#1E4FD8` ультрамарин, `#F07A1A` оранжевый.

## Титры

- Заставка / финал: название слева, маскот ДИС **справа**, не перекрывать субтитры.
- Разделители перед блоками «Демонстрация», «Результаты», «Экономика»: короткий кадр с ДИС (1,5 с) без новой озвучки — только если хронометраж остаётся в 5–7 мин.
- Не показывать `.env`, ключи, пароли, уведомление активации Windows.
