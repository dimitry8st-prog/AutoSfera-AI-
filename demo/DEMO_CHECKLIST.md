# Чеклист записи демо-видео AutoSfera AI

## Куда положить готовый MP4

После записи сохраните файл как:

`demo/video/autosfera-ai-demo.mp4`

Каталог `demo/video/` есть в репозитории (`.gitkeep`). Сам MP4 в Git **не добавлять**: он в `.gitignore`.

Формат: **MP4, 1920×1080, 30 fps**, язык русский.

---

## До записи

### Репозиторий и секреты

- [ ] Текущая ветка и SHA записаны (для этого пакета: ветка `demo/course-video-package`, приложение собрано с `build_sha` `11e0843`).
- [ ] В индекс Git не попадают `.env`, `*.db`, `logs/`, ключи, пароли.
- [ ] На экране закрыты `.env`, `.env.example` с заполненными секретами, панели JWT, логи диалогов.
- [ ] В кадре нет реальных ФИО, телефонов клиентов и адресов.

### Запуск (Windows PowerShell)

Из корня репозитория:

```powershell
Set-Location "C:\Users\user\Desktop\AutoSfera AI"
$env:BUILD_SHA = (git rev-parse --short HEAD)
docker compose up --build -d
docker compose ps
```

Дождитесь healthy у `api` и `postgres`. Проверки:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health | ConvertTo-Json -Depth 8
Invoke-RestMethod http://127.0.0.1:8000/ready | ConvertTo-Json -Depth 8
```

Ожидание `/health`: `"status":"ok"`, `"version":"3.1.0-beta.1"`, четыре агента, `"skills":17`.  
Ожидание `/ready`: `"status":"ready"`, `database.ok=true`.

Автопрогон:

```powershell
python scripts/run_demo_acceptance.py --base-url http://127.0.0.1:8000
```

Код выхода `0` только если все обязательные сценарии PASS. Результаты: `demo/results/latest.json`, `demo/results/summary.md`.

- [ ] Прогон выполнен, итог 8/8 (или актуальные числа из нового `latest.json`).
- [ ] Каждый ответ в таблице < 30 с.
- [ ] Если `/health` или `/ready` не соответствуют контракту — остановиться, заполнить `demo/BLOCKERS.md`, **не** маскировать ошибку.

### Экран

- [ ] Масштаб браузера 125–150 %, шрифт читаем с 1920×1080.
- [ ] Вкладки: презентация, `/health`, `/ready`, чат `http://127.0.0.1:8000/`.
- [ ] Не открывать DevTools Headers; для блока RAG показать только JSON **тела** ответа `/api/chat`.
- [ ] Микрофон проверен, посторонние уведомления выключены.
- [ ] Нет фоновой музыки без понятной лицензии.

### Сценарий в чате

- [ ] Каждый независимый вопрос — кнопка **«Новый чат»**.
- [ ] Многоходовой тест (фургон → администратор → гарантия) в **одной** сессии.
- [ ] Тексты запросов как в `demo/demo_scenarios.json`, без импровизации «поживее».

- [ ] Не вырезать ошибки и паузы модели.
