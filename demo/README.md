# Демонстрационный пакет AutoSfera AI

Эта папка содержит только воспроизводимые текстовые материалы для защиты проекта. Готовый MP4, голосовые дорожки и промежуточные кадры не хранятся в Git: публичная ссылка на ролик должна вести на страницу проекта `st8dom.ru`.

## Состав демонстрации

- продолжительность: 5–7 минут;
- язык и озвучка: русский, мужской голос;
- пять профильных запросов и два запроса вне темы;
- отдельная проверка переключения агента;
- демонстрация `/health`, `/ready`, `agent`, `skill`, `model_route`, `rag_ids` и эскалации;
- только вымышленные данные, без `.env`, ключей, паролей и журналов.

## Проверяемые значения

- версия: `3.1.0-beta.1`;
- агенты: 4;
- skills: 18;
- время каждого ответа: менее 30 секунд;
- внешние действия: только после подтверждения сотрудником.

Фактические результаты записываются после запуска `scripts/run_demo_acceptance.py`. Старые отчёты с 17 skills не считаются подтверждением текущей версии.
